# DCL Cricket Manager

Phone-friendly cricket tournament manager (PWA) for Blue Blasters, Golden Kings, Red Rulers, Black Titans and Yellow Riders.

## Install on Android
1. Upload all files in this folder to a public GitHub repository.
2. In the repository, open Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select branch `main`, folder `/(root)`, then Save.
5. Wait for GitHub Pages to publish. Open the shown HTTPS URL in Chrome.
6. Chrome menu (⋮) → Install app / Add to Home screen.

## Features
- Register players and bulk import players
- Add match performances per player
- Automatic player totals, batting average, strike rate and bowling economy
- Orange Cap and Purple Cap
- Player match history and team leaderboard
- Print / Save as PDF
- JSON backup and restore
- Offline app shell after first visit

## Notes
- Bowling overs use cricket notation: 3.2 means 3 overs and 2 balls.
- Player data is stored in the browser on this device. Download backups regularly.
- This starter does not sync between phones and does not include ball-by-ball scoring or automatic innings/team totals.
